# PakKom Math Adventure v2

## Fitur
- Login demo NIS, nama, kelas, avatar
- Number Forest dan Fraction Island
- 10 level, termasuk 2 Boss Battle
- Quick / Power / Ultimate Attack
- XP, koin, bintang
- Adventure Shop dan collectible
- Achievement
- Daily Quest UI
- Class Boss preview
- Teacher Command Center preview
- Progress tersimpan di localStorage
- Responsif HP/tablet/PC

## Menjalankan
Buka index.html langsung di browser.

## GitHub Pages
Upload isi folder ke root repository lalu aktifkan GitHub Pages.

## Tahap Firebase
Versi ini belum memuat kredensial Firebase agar aman dan langsung dapat diuji.
NIS sudah menjadi identitas utama sehingga berikutnya dapat dipindahkan ke Firebase Authentication/Firestore dan diselaraskan dengan PakKom Exambro.
