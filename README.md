# PakKom Math Adventure — Prototype v1.0

Prototype web game matematika responsif yang dapat langsung dibuka tanpa server.

## Fitur
- Login siswa lokal
- Number Forest
- 8 level
- Mini Boss Stone Golem
- Final Boss Forest Dragon
- XP, koin, bintang, badge
- Progress tersimpan di localStorage
- Responsif untuk HP, tablet, dan PC
- Struktur siap dikembangkan ke Firebase

## Cara menjalankan
Buka `index.html` menggunakan browser.

Untuk GitHub Pages:
1. Buat repository baru.
2. Upload seluruh isi folder ini ke root repository.
3. Aktifkan Settings > Pages > Deploy from branch > main / root.
4. Buka URL GitHub Pages yang diberikan.

## Tahap berikutnya
- Firebase Authentication
- Firestore untuk akun/progress siswa
- Dashboard guru/admin
- Bank soal yang dapat diubah guru
- Dunia tambahan: Fraction Island, Geometry City, Ratio Desert, Algebra Kingdom
- Integrasi akun/NIS dengan PakKom Exambro
