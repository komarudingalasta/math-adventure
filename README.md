# PakKom Math Adventure v2.2 — Firebase

Versi online dengan Firebase Authentication + Cloud Firestore.

Fitur:
- Login siswa NIS + password
- Login guru/admin dengan email + password
- Session login tetap aktif setelah refresh
- Profil siswa tersimpan online
- Progress tersimpan online
- Bank soal Firestore terpusat
- Tambah/edit/hapus soal khusus guru/admin
- Seed bank soal awal
- Teacher Command Center
- Firestore Security Rules berbasis role
- Number Forest + Fraction Island
- Boss battle, XP, koin, bintang

Baca `SETUP_FIREBASE.md` sebelum deploy.
